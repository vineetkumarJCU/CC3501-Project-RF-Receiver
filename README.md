# Smart Portable Radio- RF Receiver

CC3501 Embedded Systems Design Project.

## Team Members
- Vineet Kumar
- Haolin Jiang
- Harshpreet Bhullar

## Project Description
This project aims to develop a smart portable radio using the RP2040 microcontroller and SI4732 radio receiver. The device will be capable of receiving FM radio broadcasts, displaying information on a screen, logging data to a microSD card, and collecting GPS location information.

## Main Components
- RP2040 Microcontroller
- SI4732 Radio Receiver
- ST7789 Display
- MicroSD Card
- GPS Module
- USB-C Interface
- Battery Management Circuit
